# Caixa Real

Gerenciador financeiro em regime de caixa para pequenas empresas: saldo real, contas a pagar e receber, importação de extrato (OFX, CSV, Excel), relatório em cascata e ponto de equilíbrio.

- Como é publicado: ver [PUBLICAR.md](PUBLICAR.md).
- Desenvolvimento: `npm install`, `npm run dev`, `npm test`.
